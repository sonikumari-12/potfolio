# Video Editor Portfolio

A responsive, single-page portfolio website for a freelance video editor. It uses plain HTML and CSS, so there is no build step or external dependency.

## Preview locally

Open `index.html` in a browser, or enable GitHub Pages for this repository to publish it.

## Personalize before publishing

- Replace **Your Name** with your name.
- Replace `hello@example.com` with your email address.
- Update the sample project titles, years, and descriptions with your own work.
- Replace the abstract project artwork with stills or links to your films.
- Add your social profile URLs in the footer.
